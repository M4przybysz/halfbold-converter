HalfBold Converted








Description

HalfBold Converter converts plain text or HTML into a partially bolded version, making text faster to read. The converter runs fully locally, no server is needed. Built with HTML, JS, and CSS.

Features:
  1. Convert plain text or HTML to half-bolded format
  2. Adjustable bolding percentage (5-75%)
  3. Marks already bolded text in HTML with custom color
  4. Big page mode for more comfortable reading of converted plain text

Planned features:
  1. Markdown conversion support
  2. QoL additions to big page mode

How to use:

  1. Write or paste text/HTML code to convert inside the Input text area.
  2. Choose input type:
    • Plain text for plain text
    • HTML for HTML code
  3. Set bolding percentage - how much of each word should be bolded (5-75%).
  4. If you're converting HTML, choose the marking color - color to mark text that was already bolded in the input.
  5. Press the Convert button.
  6. Plain text gets converted to a ready-to-read half-bolded version. In the case of HTML, the viable text is partially bolded with <b> tags and text that was bold before conversion gets colored to the chosen marking color.

NOTE: If you're converting HTML, text outside of body and inside these tags: [h[1-6], script, style, code, pre, textarea, noscript, svg, canvas, select, math, datalist, template, iframe, object, audio, video, progress, meter, map] won't be converted by design. If there are no body tags (<body>, </body>), the entire code gets treated as if was inside of the HTML body.
