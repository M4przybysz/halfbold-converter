HalfBold Converted











Description

HalfBold Converter is a small and simple text converter inspired by Bionic Reading. It allows you to turn plain text or HTML code into their partially bolded versions, making the text faster to read by adding fixation points your eyes can lock onto to every word. The converter can run fully locally, no server is needed. Built with HTML, JS, and CSS.

Features
  • Convert plain text, HTML, or Markdown to half-bolded format
  • Adjustable bolding percentage (5-75%)
  • Adjustable minimum number of characters to bold (1+)
  • Bolding of punctuation and special characters that can be turned on/off
  • Marks already bolded text in HTML with custom color
  • Big page mode for more comfortable reading of converted plain text

Planned features
  • QoL additions to big page mode (including: customizing font, text size, page color, text color, and more)

How to use:

  1. Write or paste your plain text, HTML code, or Markdown-formatted text to convert inside the Input text area.
  2. Choose input type:
    • Plain text for plain text
    • HTML for HTML code
    • Markdown for Markdown-formatted text
  3. Set the bolding percentage (5-75%) - how much of each word should be bolded.
  4. Set the minimum number of characters to bold in each word (1 or more).
  5. If you're converting plain text or HTML, check/uncheck bolding of punctuation and special characters.
  6. If you're converting HTML or Markdown, choose the marking color - color to mark text that was already bolded in the input.
  7. Press the Convert button.
  8. Plain text gets converted to a ready-to-read half-bolded version. In the case of HTML and Markdown, the eligible text is partially bolded with "<b>" tags or "**" and text that was bold before conversion gets colored with the chosen marking color.

NOTE (HTML): If you're converting HTML, text outside of body, text inside these tags: [h[1-6], script, style, code, pre, textarea, noscript, svg, canvas, select, math, datalist, template, iframe, object, audio, video, progress, meter, map, blockquote], and HTML entities won't be converted by design. If there are no body tags (<body> and </body>), the entire code gets treated as if it was inside the HTML body.

NOTE (Markdown): If you're converting markdown, HTML entities, text inside the HTML tags from the list above, and formatted into: [headers, horizontal lines, blockquotes, tables, footnotes, code, links, images] won't be converted by design. Additionaly bolding punctuation and special characters is turned off for Markdown, because of the problems caused by Markdown's ambiguity.
